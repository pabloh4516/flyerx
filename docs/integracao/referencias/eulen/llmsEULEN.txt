## API Docs
- API Endpoints [Ping](https://docs.eulen.app/ping-12521558e0.md): The API "does nothing" except return "Pong!" if everything is OK. Additionally, it returns the JWT token in a human-readable format. Useful for checking overall API system availability and also debugging the JWT token.
- API Endpoints [Deposit (PIX ➔ DePix)](https://docs.eulen.app/deposit-pix-depix-12532107e0.md): The system generates a dynamic QR code designed for deposits in Reais (BRL) through the PIX banking system. The QR code is provided in two formats: text format, which allows for easy copy-and-paste into banking applications, and PNG format, displaying a scannable QR code image for convenience.
- API Endpoints [Deposit Status](https://docs.eulen.app/deposit-status-12667971e0.md): The `/deposit-status` API is used to retrieve the status of a financial deposit in the system. It provides information about the deposit, such as its current state, amount, and other metadata.
- API Endpoints [Deposits](https://docs.eulen.app/deposits-20408160e0.md): This API returns a list of deposits in a compact form. It may be used from time to time as a fallback in case the webhook fails.
- API Endpoints [User Info](https://docs.eulen.app/user-info-21725604e0.md): This endpoint allows for checking the limits for a specific user by EUID.
- API Endpoints [Withdraw](https://docs.eulen.app/withdraw-25979382e0.md): # How to use this API correctly
- API Endpoints [Withdraw Status](https://docs.eulen.app/withdraw-status-25979384e0.md): The `/withdraw-status` API is used to retrieve the status of a financial withdrawal in the system. It provides information about the withdrawal, such as its current state, amount, and other metadata.
